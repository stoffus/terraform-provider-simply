# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Email the repository owner at the address listed on the GitHub profile for `stoffus`, or use GitHub's private vulnerability reporting if it is enabled for this repository.

Include:

- A description of the issue and its impact
- Steps to reproduce or a minimal proof of concept
- Affected versions or commits, if known
- Any relevant logs, configuration, or Terraform examples

The maintainer will acknowledge the report, assess severity, and coordinate a fix and release as appropriate.
